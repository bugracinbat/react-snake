# Vercel Snake

A modern, Vercel-inspired implementation of the classic Snake game built with React, TypeScript, and Tailwind CSS.

## Features

- 🎮 Classic Snake gameplay with modern controls
- 🎨 Vercel-inspired design with beautiful gradients
- 🏆 Local leaderboard system
- ⏸️ Pause/Resume functionality
- 🔊 Retro sound effects
- 📱 Responsive design

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## How to Play

- Use arrow keys to control the snake
- Space bar to pause/resume the game
- Collect food to grow and increase your score
- Avoid hitting the walls or yourself
- Try to get on the leaderboard!

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite
- Vercel Analytics
- use-sound
